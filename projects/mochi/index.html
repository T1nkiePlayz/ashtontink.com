Mochi.

Your games, your way. A cross-platform desktop game launcher built around local control, flexible launch targets and optional cloud metadata — one library for every game that already lives on your computer.

// overview

One library, without replacing anything.

Mochi sits above the ecosystems you already use instead of replacing them. It gives you a single library for games living in Steam, Heroic, Epic, itch.io, Flatpak, Lutris, Bottles, Whisky/CrossOver, plain executables, scripts and apps.

Installed games stay exactly where they are. Mochi discovers them, organises them and launches them through the launcher that owns them, so prefixes, overlays and authentication keep working.

// features

What it does.

  • Library: search across names, descriptions and categories with Ctrl/Cmd + K, sorting, and a "Continue playing" shelf.
  • Organise: favourites, tags, collections and smart filters — All, Favourites, Installed, Recently played, Unplayed, Most played, Running now.
  • Per-game page: playtime, metadata, screenshots and trailer, Steam achievements and mod management.
  • Decide what to play: a backlog (Want to play / Playing / Finished / Dropped), a wishlist, and "What should I play?" that picks by mood and time.
  • Quality of life: guided first-launch setup, themed confirmations, an in-app notification centre and desktop notifications.
  • Themes: a themed UI with your choice of look, stored per profile.
// local_first

Local first, cloud optional.

The library, launching, playtime, themes and settings all work without an account and without a network. If you do sign in, cloud sync is optional and metadata-only — your installations never move.

That decision shapes the rest of the design: there is no server in the critical path, and nothing stops working when the internet does.

// platforms

Native where it matters.

OS-specific code lives in its own modules, and the UI asks the platform what it can do instead of assuming an OS. Linux packages ship as AppImage, deb and rpm; macOS ships as a DMG. Windows is not supported at the moment.

// verification

Verify before you run it.

Every release file carries a GPG signature and a GitHub build attestation, with SHA256SUMS.txt published alongside. macOS builds are ad-hoc signed only, so Gatekeeper asks on first launch — the site documents how to open it safely.

// the_website

Mochi has its own site.

Mochi-Website is the public site, documentation and signed-in account portal: downloads, a changelog read live from GitHub releases, accounts, cloud-sync settings and service keys. React 19, Vite, Tailwind and Supabase, MIT licensed.

// project_note

Early, but real.

Mochi is in early development: storage formats, features and UI may change between versions, so treat your own backups as the source of truth for your library. It's also the project teaching me the most about shipping software people actually install — packaging, signing, verification and documentation included.
